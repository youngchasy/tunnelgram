# tunnelgram 2.0

Крупное обновление tunnelgram.

## Главное

- Два режима работы: MTProto → Telegram WSS и локальная HTTP/SOCKS5-прокси.
- Внешние подключения через HTTP/HTTPS, SOCKS4/5, VLESS и Hysteria2.
- Автоматическая проверка профиля и запуск через встроенный sing-box.
- Сборки для Windows x64, Linux x64, macOS ARM64 и macOS Intel.
- Исправлено создание временного sing-box-конфига в Windows.
- Исправлено отображение ANSI-кодов и русских имён сетевых интерфейсов в логах.

## Использование

Распакуйте архив для своей системы целиком. Не отделяйте `sing-box` от приложения. Для Telegram в режиме локальной прокси используйте SOCKS5 `127.0.0.1:9443` или нажмите кнопку **Telegram** в программе.
